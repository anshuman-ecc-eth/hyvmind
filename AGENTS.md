# Project Guidance

## User Preferences

- prefer `gameZoom = 2` for both main world and terrain world (camera viewport shrinks from 500x500 to 250x250, CSS-scaled 2x to fill screen; ~31 tiles visible around player)
- dodge roll: Space key or Roll button, 0.3s duration, 0.3s cooldown, 1.78× walk speed, 3-frame animation (LoL-style). Roll sprites at `/assets/hyvmind/sprites/lua_roll_[d/u]_[0-2].png`
- Settings button (top) opens overlay with Audio toggle + Screen Size cycle. Screen Size button was removed; Roll button sits in its place under Z/X buttons.

## Verified Commands

**Frontend** (run from `src/frontend/`):

- **install**: `pnpm install --prefer-offline`
- **typecheck**: `pnpm typecheck`
- **lint fix**: `pnpm fix`
- **build**: `pnpm build`

**Backend** (run from `src/backend/`):

- **install**: `mops install`
- **typecheck**: `mops check --fix`
- **build**: `mops build`

**Backend and frontend integration** (run from root):

- **generate bindings**: `pnpm bindgen` This step is necessary to ensure the frontend can call the backend methods.

## Learnings

- **Funding tab (Juicebox V6)**: `pages/FundingView.tsx` is a client-side EVM integration (Base mainnet + Base Sepolia). Deps `viem@2` + `wagmi@3` (peer deps compatible with React 19.1 / TS 5.9 / @tanstack/react-query 5). `providers/JuiceboxProvider.tsx` mounts `WagmiProvider` with its **own** QueryClient (the app-wide client uses `staleTime: Infinity` and would freeze on-chain reads). Wallet is a parallel identity to Internet Identity; no backend/Motoko changes, keys stay in the user's wallet.
  - Deployment addresses live in `src/data/juicebox/{base,baseSepolia}.ts`, generated by `scripts/fetch-juicebox-deployments.mjs` from `Bananapus/deploy-all-v6@316e9d4/deployments/<chain>/` (addresses only — full ABIs are NOT shipped to keep the bundle small; the app uses minimal typed ABIs in `src/lib/juicebox/abis.ts`).
  - Signatures verified against `nana-core-v6@89ac631`: `JBMultiTerminal.pay(projectId, token, amount, beneficiary, minReturnedTokens, memo, metadata)` (native pay = `NATIVE_TOKEN` `0x...EEEe` sentinel, `amount` ignored, `msg.value` used), `previewPayFor`, `cashOutTokensOf`, `previewCashOutFrom`, `currentSurplusOf(projectId, [], 18, 1)` (currency 1=ETH). `JBRuleset.weight` is `uint112` + `weightCutPercent` `uint32` (NOT 176/decayRate). `currentRulesetOf` returns `(JBRuleset, JBRulesetMetadata)` tuple. Terminal resolved via `JBDirectory.primaryTerminalOf(projectId, token)`; previews target the same resolved terminal as the writes (preview/execution coherence). USDC Base = `0x8335…2913`, USDC Base Sepolia = `0x036C…CF7e`, WETH = `0x4200…0006`. Revnet names 1-7 local map in `config/juicebox.ts`.
  - **Graph → project builder**: every published graph can be launched as its own Juicebox project on Base. Backend `EvmRecovery.mo` verifies a MetaMask `personal_sign` (EIP-191) on-canister via mops deps `libsecp256k1` (av1ctor, `recover_with_context` = ecrecover) + `sha3` (hanbu97, `Keccak(256)` = Ethereum keccak; base pinned to `f8112331…` — its Buffer needs `toVarArray`). `linkWallet(wallet,message,sig)` binds one wallet↔principal (message must contain `Principal: <caller>`, replay-protected by `lastNonce`); `recordJuiceboxProject(graphId,projectId,chainId,wallet)` is creator-gated. Launch = one `JBController.launchProjectFor(owner,projectUri,rulesetConfigurations[],terminalConfigurations[],memo)` tx, `value: 0.0001 ETH`, returns projectId; frontend decodes the `JBProjects.Create` event from the receipt then records the mapping. `JBMultiTerminal` accounting-context `currency` for native = `uint32(uint160(NATIVE_TOKEN))` = **61166** (distinct from ruleset `baseCurrency` 1=ETH). viem maps uint48/uint32/uint16 tuple fields to `number`, uint112/uint224/uint256 to `bigint`. Wizard defaults: duration 0, weight 1e18, reserved 0%, tax 0%, no splits/fund limits, canonical terminal + NATIVE_TOKEN.
  - Dev server note: `pnpm dev` at repo root fails ("Command dev not found" — root has no dev script); run `npx vite` from `src/frontend/`.

  - Path: `/assets/lua/` (overworld.png, lua-tree.png, lua-tree2.png, lua-tree-shadow.png)

- Voxel world (`/assets/voxel/voxel-world.html`) is a Three.js (WebGL) Minecraft-style explorer over the same perlin/biome terrain as terrain-world.html. Vanilla ESM: `voxel.js` imports `three.module.min.js` (copied from `node_modules/three/build`). Chunked meshing with face culling (16×16 chunks), pointer-lock WASD + jump + AABB collision, DDA raycast break/place, translucent water. Entered per-terrain from MapsOverlay's voxel-only list, seeded with the selected graph's name via `?seed=`; Back button posts `hyvmind-close`. `voxel.js` posts `hyvmind-terrain-ready` to the parent after the first rendered frame so TextGameModal's "Travelling.." loading overlay clears. The 2D terrain world (`terrain-world.html`) is no longer reachable from Maps (voxel-only); the file stays on disk as the generation reference.
  - Terrain **artwork** for published graphs is generated by `src/utils/perlinTerrainGenerator.ts` with the **same params as the voxel world** (3 octaves, exponent 2.2, `fnv1a(name)` seed, 20th-percentile water level), so the Maps-overlay artwork is the exact top-down image of the voxel terrain. Stored on the graph via `updateSourceGraphArtwork` + `updateSourceGraphTerrainParams` at publish time (`usePublishGraph.ts`).
  - Block **textures** come from `assets/voxel/textures/` (14 tiles from [vyse12138/minecraft-threejs](https://github.com/vyse12138/minecraft-threejs), MIT) packed into a **runtime canvas atlas** (`TEX_NAMES`/`buildAtlas`; NearestFilter, no mipmaps). The mesher emits a `uv` attribute; `texSlot(t, faceIdx)` picks the tile per block+face (grass top/side/dirt-bottom, log side/top). `blockColor` now returns a **shading tint** (top-light 1.22/0.78 + `h3` speckle) multiplied over the texture; `C[]` is kept only for the minimap. `makeBlockBoxGeometry(t)` builds a textured unit cube for crumb particles.
  - vyse-style features added: targeted-block **highlight** (translucent box re-raycast each frame, `updateHighlight`), **auto-repeat** break/place on hold (333 ms interval, cleared on mouseup/blur/unlock), **wheel** block cycling (100 ms throttle; `HOTBAR_BLOCKS`), **crumb particles** (`spawnCrumb`/`updateCrumbs`, 250 ms shrink), **place-overlap guard** (`cellOverlapsPlayer`), and a bottom-center **hotbar** (icons drawn from the atlas) + FPS counter + PAUSED overlay (reuses `#hint`) + `+` crosshair.
  - Voxel audio: settings **Birdsongs** toggle (renamed from Music) plays `/assets/hyvmind/birds.mp3` (mp3, `preload="none"`, volume **0.5**), started via `startBirdsong()` on first pointer lock and kept playing through the pause menu; stopped on exit. The **Sound** toggle gates spade break/place SFX from `assets/voxel/sfx/` (24 mp3s converted from vyse12138/minecraft-threejs oggs, MIT, volume 0.15, cycled 4 variants per material via `playSfx`) plus the jump SFX `assets/voxel/sfx/jump1.mp3` (Yo Frankie! — Blender Foundation, CC-BY 3.0, played via `playJump()` on Space in walk mode at `vy = 8.2`). Audio must stay **mp3**: the deploy pipeline serves `.ogg` assets base64-encoded (unknown extension → treated as text), which browsers can't decode — only known extensions like `.mp3` upload as raw binary.
  - Voxel world **UI text conventions**: the voxel UI uses **Press Start 2P** (self-hosted at `/fonts/press-start-2p.woff2`) — only the graffiti 3D texture uses Finger Paint. All user-facing text (tooltips, modal titles/labels, HUD, node-details rows) is **sentence case**; physical key names (WASD/SPACE/F/V) and API/user data (node names, edge labels, graffiti text) keep their own case. Hover **tooltips expire after 1s** even while the crosshair stays put: `showToolTip(text, key)` only refreshes the timer when the `key` changes (`'shield:x:y:z'`/`'armor:x:y:z'` for blocks, `'cube:'`/`'edge:'` + `object.uuid` for the sky tree); `clearTooltipKey()` is called when nothing is targeted (and must NOT run when `updateSkyHover` gets a `null` dir — shield/armor branches rely on that). Action tooltips (shield hits, weight +/- ) still refresh each action by design.
  - Voxel **sky graph tree**: `voxel.js` self-contains the feature (`initSkyTree` → `buildSkyTree`, after `startGame`). It resolves the API base from `/env.json` `backend_canister_id` (localhost → relative `/api` via the Vite dev proxy, then falls back to the live `https://<cid>.raw.icp0.io`; dev falls through to the live API when the local backend is down), fetches `/api/graphs` and matches the `?seed=` graph **name** → id, then `/api/nodes/{id}` (flat array with `id`/`name`/`type`/`parentId`) and `/api/edges/{id}` (cross-refs only, `{source,target,label,bidirectional}`). All responses are sanitized with `/[\u0000-\u001f]/g → ' '` before `JSON.parse` because the backend emits raw control chars in `content`. Renders a **chandelier** of coloured cubes (canonical `NODE_COLORS`), translucent white parent→child beams, thin indigo (`0x9db4ff`) cross-ref beams (drawn only when both endpoints survive the collapse, deduped by `(min,max)` id pair). There are **no 3D labels** — names appear via crosshair hover tooltips (`updateSkyHover` via `THREE.Raycaster`, cubes win over beams; beam hover shows `REF — src → tgt`). **Left-click** a cube opens the `#node-details` modal (populated from the full API node object kept in `skyNodeData`: id/creator/createdAt/attributes/tags/sources/content, `—` when absent; `content` exists only on interpEntity, avg ~1KB → modal is scrollable). It mirrors the graffiti flow: `nodeDetailsOpen` guards `pointerlockchange`/ESC/canvas-click; ESC-close reuses the `escToResume` keyup-deferred re-lock; Close button calls `requestLock()` (click = user activation). `worldMaxH` feeds `rootY = max(130, worldMaxH+92)` so the tree bottom clears the terrain. Nodes are a **standalone `THREE.Group`** — never written to `voxels`/`builtChunks`/`crumbs`/`graffitiList`, so no minimap pollution or backend persistence. Oversized graphs collapse subtrees bottom-up to `SKY_BUDGET = 300` (cluster cubes get a dark marker + `userData.count`). Pitfalls learned: the root must be excluded from its own `children` map (null `parentId` fallback otherwise creates a self-cycle → infinite recursion), a visited-set BFS prunes any cyclic `parentId` in real data, the collapse walk must push **ids** (`g.id`) not node objects (`hidden.add(c.id)` on a string silently adds `undefined`), and real graphs vary wildly in type mix (Cheng 2020 = curation/swarm/interpEntity only, no law/location). Falls back to a deterministic 46-node demo graph when the seed matches nothing.

- **Blog posts are password-gated and stored on-chain** in the `backend` canister (HTML body + optional banner). Content is **never in the repo** — the old static `src/frontend/public/blogs/` files were removed (backup: git tag `blogs-v1-pre-removal` + `scripts/blogs_backup/`, both git-ignored). The password gate is enforced **on-chain**: `getBlogPosts`/`getBlogPostContent` are `shared` (update) methods that return data only when the supplied digest matches `SHA-256(salt ++ password)` — so there is no public query to bypass. The reader (`BlogsView.tsx`) uses an anonymous agent (`AnonymousIdentity`, pattern from `TutorialView.tsx`) so **no login is required** — the password is the credential. Gate deterrence only (scrapers/crawlers); a human with the password reads posts.
  - **Set/rotate password**: terminal command `/setpw <password>` (admin) → computes `salt`+`SHA-256(salt++pw)` (Web Crypto) + a vetKeys IBE admin-recovery ciphertext, calls `setBlogPassword`. Backend stores salt/hash/ciphertext; `getBlogPasswordConfig` (public query) exposes salt/hash safely (preimage-infeasible). Dep `@dfinity/vetkeys@0.4.0` added for the recovery ciphertext.
  - **Register a post (admin)**: stage in `scripts/blogs/staging/<slug>/` (`post.json` with `{id,title,author,published,lastEdited}` + `article.html` + optional `banner.png`), then run `BACKEND_CANISTER_ID=<id> ADMIN_SECRET_HEX=<64-hex> node scripts/blog-admin.mjs` (or `ADMIN_KEY_JSON`). It calls `setBlogPost` (upsert by `id`; empty `article.html` deletes). Full details in `scripts/blogs/README.md`.
  - On-chain storage keeps banner (~1MB) under the 2MB reply cap. Backend methods: `setBlogPassword`/`clearBlogPassword`/`setBlogPost` (admin), `getBlogPasswordConfig` (query), `getBlogPosts`/`getBlogPostContent` (gated shared), `getBlogPasswordPublicKey`/`deriveBlogPasswordVetKey` (vetKD recovery plumbing).
